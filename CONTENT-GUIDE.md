# What to edit before you publish

Everything below lives in `index.html`. Search for these exact snippets and replace them.

1. **Page title** — `<title>Lainey — Design Portfolio</title>`
2. **Your name in the nav** — `<a href="#top" class="nav-name">Lainey</a>`
3. **Hero headline** — the `<h1>` right after `<!-- EDIT ME: name + one-line pitch -->`
4. **Bio** — the two `<p>` tags inside `<div class="about-bio">` (currently placeholder text, including `[your city]`)
5. **Contact links** — inside `<ul class="contact-list">`:
   - Replace `hello@example.com` (appears twice — once in the visible text, once in `mailto:`)
   - Replace the LinkedIn URL `https://www.linkedin.com/in/yourname`
   - Replace or remove the Instagram link
6. **Footer year/name** — `&copy; 2026 Lainey. All work shown remains the property of the artist.`

Everything else (captions, section text) is already written from your actual project names — feel free to rewrite any caption to be more specific (client name, your role, tools used).
